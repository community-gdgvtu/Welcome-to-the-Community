# Welcome to the Community

Welcome to the **GDGoC VTU Belagavi** contributor practice repository!

This repository is a safe first step into Git and GitHub collaboration. You do not need to build a full application here. Your task is to make one small, meaningful contribution and learn the open-source workflow.

## What you will practise

- Understanding a repository and its files
- Reading and writing Markdown
- Forking and cloning a repository
- Creating a branch and a commit
- Pushing to your own fork
- Opening a pull request for review

## Make your first contribution

1. Fork this repository to your personal GitHub account.
2. Clone **your fork** to your computer.
3. Create a branch such as `add-your-username`.
4. Copy `contributors/_template.md` to `contributors/your-github-username.md`.
5. Replace the placeholders with a short introduction.
6. Commit and push your change to your fork.
7. Open a pull request to this repository's `main` branch.

Read [CONTRIBUTING.md](CONTRIBUTING.md) before submitting.


## What belongs in a profile?

A name or preferred display name, your public GitHub profile link, broad technical interests, and one optional fun fact. Do not add phone numbers, home addresses, passwords, API keys, private email addresses, or other sensitive information.

## A note about this repository

A pull request is a proposal, not an automatic merge. Maintainers may ask for changes or decline contributions that do not follow the guidelines. Be respectful in reviews and patient while maintainers review contributions.
